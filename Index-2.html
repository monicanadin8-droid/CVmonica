Apa itu HTML?

HTML (HyperText Markup Language) adalah bahasa markup standar yang digunakan untuk membuat dan menyusun struktur halaman web serta kontennya.

Struktur Dasar HTML

Setiap dokumen HTML memiliki kerangka dasar yang wajib ada agar dapat dibaca oleh browser dengan benar:

<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>Judul Web</title>
</head>
<body>
    <h1>Halo Dunia!</h1>
</body>
</html>

Elemen Populer dalam HTML

  • <h1> sampai <h6>: Digunakan untuk membuat judul (heading).
  • <p>: Digunakan untuk membuat paragraf teks.
  • <a>: Digunakan untuk membuat tautan (link).
  • <img>: Digunakan untuk menampilkan gambar.
